# Critter Coral

A tiny, dependency-free web app for tracking critters in your coral reef.

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Features

- Add a critter with name, species, and mood.
- Remove individual critters.
- Clear all critters.
- Roster is saved in browser local storage.
